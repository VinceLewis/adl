# REQ-0001: Deterministic storage names for declared model names

ADL derives a predictable, safe storage name from every declared object or
field name. The acceptance examples deliberately cover ordinary CamelCase,
separator canonicalisation, the numeric-leading identifier boundary, and an
otherwise unusable input: together they document the compact normalisation
contract without treating prose or scenario wording as a classifier.
