# REQ-0002: Declared surfaces are reachable in the running application

A person using a mounted ADL application can reach every surface the model
declares, and a list surface shows that object's declared fields. The examples
below are browser acceptance: they exercise the production files a build
produces, through the navigation a person actually uses, rather than asserting
against the model in memory.
