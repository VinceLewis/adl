# AC-0003: Numeric-leading names remain valid storage identifiers

When canonicalisation leaves a name beginning with a digit, ADL adds the
identifier-safe leading underscore. This boundary is distinct from ordinary
word conversion because a numeric prefix must not be emitted unchanged.
