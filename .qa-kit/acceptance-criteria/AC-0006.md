# AC-0006: Opening a list surface shows that object's declared columns

Selecting a list surface replaces the displayed surface, marks the chosen
navigation item as the active one, and renders one column per declared field of
that object. This is the boundary the runtime is most likely to get wrong when
a model declares more than one object: the previous surface's columns surviving
the switch would be indistinguishable from a correct render to anyone reading a
screenshot alone.
